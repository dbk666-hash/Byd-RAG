# CFQA改编的比亚迪50题 · v1

这是一组从[ygan/CFQA](https://github.com/ygan/CFQA)官方按年份测试集选择意图、迁移到比亚迪年报后重新标注的本地评测集。**不是原版CFQA测试成绩，也不是纯口语或独立盲测。**

## 题集与来源

- 共50个不同查询目标，归为8个方向：证券与治理9、业务与战略9、财务指标11、员工与激励4、解释与口径3、研发与技术6、客户与供应链2、现金流6。没有把同一问题换年份重复凑数；相关指标仍可能共享同一张原表。
- 原始问题均来自`dataset/split_by_year/split_by_year_test.json`，官方文件共2084条，blob版本`ebb3b7ac5e18741534677bdd3dba9a5b3dcb49ce`。不混入train/dev。
- 每题保留完整`source_original`（含原公司、原问题、原答案、出处及编号）。其他公司的答案仅供来源追踪，**不作为比亚迪金标**。
- 改编问题均围绕2022年比亚迪年报；员工人数同比题还需要2021年报告，保留“去年”的自然表达。这会检验隐含比较年份的处理，不能因当前年份过滤排除了2021证据就修改金标迎合系统。
- 有些源题是片段式自然问法，有些仍用专业术语。迁移中允许补公司名、澄清年度范围或轻微改述，但不宣称这些改编文本是原封不动的真实用户日志。
- 为保证可标注性，本轮选择可在现有语料核验的目标，不是随机抽样，可能有选择偏差；不能外推全部CFQA或真实用户分布。

## 文件

| 文件 | 用途 |

原50题`eval/questions.jsonl`和官方测试集原样比亚迪5题`eval/cfqa/byd_year_test.jsonl`均保留，不覆盖或混入本文件。

## 运行

从Byd-RAG根目录，在已配置解释器/密钥的环境中执行：

```powershell
# 先跑5题检查调用和输出
python src/evaluate.py --questions eval/cfqa_adapted/byd50_v1/questions.jsonl --limit 5
# 再跑完整50题
python src/evaluate.py --questions eval/cfqa_adapted/byd50_v1/questions.jsonl --limit 50
```

结果写入`eval/runs/`，逐题保存回答、证据、提示词、耗时与错误。现有脚本的默认输入未改，**必须显式传--questions**才使用这组题。创建本数据集没有调用模型，离线入口检查中的占位回答不是真实评测结果。

## 标注与评分

每条比亚迪证据含原文摘录、所在解析文件、字符偏移、年份及PDF物理页序（从1开始，不是印刷页码）。60条证据摘录均逐字符匹配当前解析文本，并与原PDF同页提取文字去空白后交叉核对；抽查8页关键财务/人员/股东表的视觉布局。计算题用Decimal复算。此为本地源文核验草稿，**未经过独立第二人审阅**。

评估时：

1. 先核对检索/最终上下文是否包含必要事实、字段、年份、单位和口径；接受已核验的其他等价出处，不只认固定页码。
2. 再核对答案是否完成任务、计算正确、引用支持充分；接口200不等于回答正确。
3. 金额允许元/千元/万元/亿元等价表达；单位换算后比较数值。比例默认按两位小数比较，容差0.005个百分点；精确整数/人数/股数不得靠模糊字符串命中。
4. “没有优先股/没有可转债”有明确年报证据，是可回答的否定事实，不是缺文档或检索为空。
5. 第一大股东、国内外业务占比、产能利用率等问题允许请求澄清，或明确限定口径后回答；不能强制只有一个裸数值正确，也不能把HKSCC代理持股合计当实际控制人。
6. 研发费用/研发投入、合并/母公司、股数/股本金额、同比百分比/百分点必须区分。年度分红预案与当年执行的上一年度分红也必须区分。
